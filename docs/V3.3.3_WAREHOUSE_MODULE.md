# NuhaMart v3.3.3 — Warehouse Management

## Included

- Warehouse CRUD with permission checks
- Unique warehouse code
- Contact person, phone, email and address
- Active/inactive status
- Single default warehouse enforcement
- Default warehouse deletion protection
- Search, status filter and pagination
- Soft deletes
- Repository interface, repository, service and FormRequest layers
- React/Inertia pages and sidebar entry

## Upgrade

```bash
php artisan migrate
php artisan db:seed --class=RolesAndPermissionsSeeder
php artisan optimize:clear
npm install
npm run build
```

The Super Admin role receives all warehouse permissions automatically when the permission seeder runs.
