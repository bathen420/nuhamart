# NuhaMart v3.3.3 — Customer & Supplier Groups

Adds customer groups with percentage/fixed discounts and credit limits, plus supplier groups with payment terms. Both modules include CRUD, validation, search, status filters, soft deletes, permissions, repository/service architecture, and Inertia React screens.

## Upgrade

```bash
php artisan migrate
php artisan db:seed --class=RolesAndPermissionsSeeder
php artisan optimize:clear
npm install
npm run build
```
