# Changelog — NuhaMart v1.2.0

## Added
- Financial dashboard with revenue, expenses, profit, cash/bank, receivables and payables.
- Trial Balance with opening, period and closing debit/credit columns.
- Profit & Loss statement.
- Balance Sheet with accounting-equation difference indicator.
- Cash Flow statement grouped into operating, investing and financing activities.
- Date/as-of filters.
- Browser print support.
- UTF-8 CSV exports for all four statements.
- `financial-statements.view` and `financial-statements.export` permissions.
- Sidebar navigation entries.
- Financial statement route and calculation tests.

## Compatibility
Built for NuhaMart v1.1.0 Automatic Accounting Engine on the latest full-project baseline.
