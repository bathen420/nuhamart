# Nuha Mart BD v2.2.0 — Launch Ready Commerce

## Added
- One-screen admin order workflow for status, payment, courier, tracking and internal notes.
- Dhaka, outside-Dhaka and free-shipping settings in Business Settings.
- Manual bKash, Nagad and bank-payment information settings.
- Facebook and YouTube business links.
- Product SEO title and description storage foundation.
- Dynamic XML sitemap and production robots.txt.
- Production environment example and launch preparation scripts.
- Regression tests for launch routes and database fields.

## Compatibility
This release upgrades the existing v2.1 Lean Commerce database without deleting products, customers, orders or accounting records.
