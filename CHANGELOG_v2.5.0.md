# Nuha Mart BD v2.5.0 — One-Page Checkout

## Added
- Home delivery and zero-charge store pickup selection.
- Business-setting based Dhaka and outside-Dhaka delivery charges.
- Free-shipping threshold shown live and enforced on the server.
- Bank transfer payment option with mandatory reference validation.
- Admin-configured bKash, Nagad and bank instructions on checkout.
- Mobile sticky total and Place Order action.
- Saved-address support retained for authenticated customers.
- Duplicate-submit protection through Inertia processing state.
- Feature tests for store pickup, free shipping and bank reference validation.

No migration is required.
